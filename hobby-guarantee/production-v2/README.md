## 사용 안내

파일은 H001_START.png / H002_END.png 형식이며 images 폴더에 있습니다. 같은 START를 종료에도 쓰는 컷은 END 사본이 없습니다. 저장소를 다운로드한 뒤 player.html을 열면 전체 음원에 맞춰 START/END 이미지가 자동 전환됩니다. gallery.html은 나란히 비교용입니다. GitHub 자체는 HTML을 실행하지 않으므로 위 Markdown 이미지 페이지 또는 MP4를 이용하세요.

MP4는 수정 START/END와 2D 팬·줌으로 구도·리듬을 확인하는 미리보기입니다. 실제 인물 모션·3D 카메라 이동을 생성한 완성 뮤비는 아닙니다. 타임코드는 제공 SRT 기준이고 최종 비트 그리드는 별도 검수 대상입니다. AI 컷 사이 천 주름·가구·미세한 얼굴 차이는 영상 연결 단계에서 맞춥니다.

[컷 선택 가능한 MP4 재생기](watch.html) · [원본 이미지 자동 전환 재생기](player.html)

미리보기의 팬·줌은 2D 편집 효과이며, 인물 모션이나 실제 3D 트래킹·아크를 생성한 결과는 아닙니다. 수정한 카메라 시작·종료 구도와 곡 전체 흐름을 확인하는 용도입니다.
