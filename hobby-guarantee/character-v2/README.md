# 취미 활동은 보장해 줍쇼 · 여주 수정 시안 v2

사용자가 올린 얼굴 사진을 참고해 여주인공만 수정한 디자인 제안입니다. **사용자가 본 시안을 확정했습니다. 남주는 기존 시안을 유지합니다.**

![여주 얼굴·전신 수정 시안](HEROINE_V2_PROPOSAL.png)

[이미지 원본 다운로드](https://github.com/dbtjs4848-lgtm/-/raw/refs/heads/main/hobby-guarantee/character-v2/HEROINE_V2_PROPOSAL.png)

- 얼굴: 사용자 사진의 눈·코·입·윤곽에 가깝게, 볼만 살짝 부드럽고 통통한 느낌.
- 머리: 사진처럼 검은색 옆 가르마 턱선 단발. 이전 갈색 묶음머리를 대체하는 제안.
- 체형: 가슴·골반을 과장하지 않고 전체적으로 균형 있는 자연스러운 볼륨. 허벅지·종아리는 슬림하고 무릎·발목으로 이어지는 선을 유지.
- 복장: 코랄색 라운드넥 니트, 진한 인디고 스키니진, 크림색 스니커즈.
- 그림체: 한국 생활 코미디 웹툰풍. 얼굴 확인용 확대 모습과 체형·바지 선 확인용 전신을 함께 배치.

[변경하지 않은 남주 기준](../test-v1/images/CHARACTERS_PROPOSAL.png) · [기존 꽁트 테스트](../test-v1/README.md)

기존 게임·쇼핑·낚시 테스트는 수정 전 여주가 등장하는 이전 비교 자료로 보존했습니다. 확정된 새 얼굴·단발·체형·스키니진을 production-v1 본편 제작에 적용합니다.
