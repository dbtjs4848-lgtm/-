# 최종 v6 이미지 제작 기준

52컷 / START 52장 + END 36장 = 88장. 16컷은 제자리 루프형으로 같은 시작 키프레임을 종료에도 공용한다. 공용은 파일을 복사하지 않으며 manifest와 CSV에 표시한다.

이전 33컷 이미지를 재활용하거나 9칸 보드를 잘라 쓰지 않는다. 모든 컷은 독립 가로 16:9 이미지로 생성한다. 같은 컷의 END는 생성된 START를 직접 참조한다.

점퍼 이상 주머니는 화면 오른쪽으로 통일한다. 반환 때도 같은 주머니를 보여준다. 서온의 자기 걱정은 앞치마 안쪽에 잠재해 움켜쥘 때 불거지며, 무심코 손을 옮긴다고 해결되지 않는다. 의식적으로 접힘을 펴는 38컷에서 분리된다.

32컷은 같은 미디엄 안에 얼굴과 주머니를 함께 넣어 표정과 결과를 읽힌다. 47컷은 같은 와이드 안에서 의자까지 이동한다. 24컷만 의도한 짧은 하늘 틸트를 허용한다. 공용 컷에서는 긴 이동 대신 그 위치에 머무는 미세 움직임으로 연출한다.
