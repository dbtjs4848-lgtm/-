Flova 업로드 안내

이 자료는 기존 45컷과 이미지 54장을 Flova에서 연결하기 위한 패키지입니다.
Flova 프로젝트에 자동으로 업로드하거나 실행한 상태는 아닙니다.

1. 00_flova_storyboard.zip과 이미지 ZIP 5개를 PC에 다운로드합니다.
2. ZIP을 모두 압축 해제합니다. 이미지 ZIP은 9컷씩 나눴으며 중복 없는 PNG 원본입니다.
3. Flova 화면 오른쪽 아래 입력창의 + 또는 왼쪽 '프로젝트 파일'의 + 메뉴를 열어 파일 첨부/업로드 항목을 확인합니다. 스크린샷만으로 정확한 메뉴명·확장자·업로드 제한은 확인되지 않았습니다.
4. 우선 07_audio.mp3와 03_storyboard.pdf를 첨부합니다. 이어서 images 폴더의 PNG를 업로드합니다. CSV/TXT/MD 첨부가 지원되면 해당 파일도 첨부하세요. ZIP을 직접 읽는다고 가정하지 말고 압축 해제한 파일을 사용하세요.
5. 02_flova_prompt.txt의 내용을 채팅에 붙여넣습니다. MD/CSV 첨부가 안 되면 05_all_cuts.md를 9컷 단위로 나눠 붙여넣을 수 있습니다. 각 이미지 ZIP에도 해당 9컷의 명세와 붙여넣기 문구가 있습니다.
6. 먼저 C01–C09 묶음으로 이미지 연결을 확인하고 C10–C45를 차례대로 추가합니다. 기존 컷을 다시 생성하거나 지우지 않도록 묶음 지시문을 사용하세요.
7. 45컷 길이와 이미지 참조가 확인되면 선택한 컷부터 영상화하세요. 일괄 영상 생성과 유료 실행은 초기 지시문에서 요청하지 않았습니다.

파일명 예:
C01_start_end_F001.png: C01의 시작/종료 공용 이미지 한 장.
C06_start_F006.png / C06_end_F007.png: C06의 서로 다른 시작/종료 이미지.
같은 프레임은 중복 복사하지 않았습니다. 45컷, 이미지 54장입니다.

주의:
음원은 마스터로 한 번만 사용합니다. 컷마다 별도 BGM을 만들지 않습니다.
74 BPM은 리듬 신호 추정값이며 실제 다운비트·가사 단어 싱크를 확정한 값은 아닙니다.
CSV의 소수점 길이는 편집 목표입니다. 24fps 편집에서는 가장 가까운 프레임으로 경계를 정렬하세요.
영상 생성기의 지원 길이·시작/종료 프레임 기능은 선택 모델에서 확인해야 합니다.
PDF에서 이미지가 자동 추출된다고 가정하지 마세요. 이미지 파일명과 별도 PNG 연결을 확인하세요.
